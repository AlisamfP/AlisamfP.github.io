# Photo wallpapers

Drop image files in this folder, then register each one in
`src/components/Desktop/wallpaper-photos.ts` so it shows up as an option
in Settings → Background.

**Format tips:** JPG or WebP, landscape orientation, at least 1920×1080.
Keep files under ~500KB where you can — these render full-bleed behind
the desktop and aren't optimized/resized at build time.
